TIKA XR — setup + test

True world-lock: text real surface pe anchor hota hai, tum chalke dekho to bhi wahin rehta hai.
Requirements: Android + Chrome + ARCore ("Google Play Services for AR"). iOS Safari support nahi. Page HTTPS ya localhost pe khulna chahiye — file:// se AR nahi chalega.
  1. USB wala tareeka (fully local): PC pe folder me python -m http.server 8000 chalaо. Phone USB se jodo, USB debugging on, phir adb reverse tcp:8000 tcp:8000. Phone Chrome me kholo http://localhost:8000/tika-xr.html — ye secure context mana jata hai.
  2. Ya HTTPS: file ko kisi bhi static HTTPS host pe daal do (GitHub Pages / Netlify). Tool khud koi network request nahi karta — sirf page serve hota hai.
  3. Page kholo → Enter AR → camera permission Allow.
  4. Phone dheere ghumao, zameen/table pe green ring aayegi → tap karo → text anchor.
  5. Ab chalke idhar-udhar dekho — text wahin tika rahega (6DoF SLAM). Yahi true world-lock hai.
  6. Re-place se dobara lagao, Exit se bahar.
