GEOHUNT — kaise chalega

Real 3D text + coordinate clue + QR/link + hunter mode. Sab local — koi server nahi.
Requirements: 3D Studio har browser me chalega. GPS/Camera permissions browser se milenge. Camera AR ke liye HTTPS/localhost best hai. True centimeter-level world-lock ke liye marker/VPS chahiye; ye GPS-radius hunt hai.
  1. File ko geohunt.html save karo aur Chrome me kholo. 3D preview turant dikhega.
  2. Left me text + 3D controls badlo — live solid mesh update hoga.
  3. Location daalo (GPS ya manual lat/lon), radius set karo, Save clue dabao.
  4. Share link/QR dost ko bhejo. Link me clue data encoded hai — koi server nahi.
  5. Hunter link khole → Hunt mode → Start GPS → distance/bearing follow karo → radius me aane par clue reveal.
  6. Camera button se live camera par 3D text overlay dekho (GPS-direction based, approximate).
